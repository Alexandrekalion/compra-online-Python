# Simulacao Educacional de Compra Online em Python

Projeto de estudo em Python que simula, pelo terminal, o fluxo basico de uma compra online com coleta de dados, valor da compra e confirmacao por senha.

Este repositorio deve ser interpretado exclusivamente como exercicio didatico. Ele nao processa pagamentos reais, nao se conecta a adquirentes, nao valida cartoes e nao deve receber dados pessoais ou financeiros reais durante a execucao.

## Objetivo do estudo

O exercicio foi criado para praticar entrada de dados no terminal, conversao de tipos, condicionais e repeticao. O cenario de compra foi usado apenas como contexto para organizar as perguntas feitas ao usuario e demonstrar uma confirmacao simples.

## Problema praticado

Durante os primeiros estudos de programacao, e comum precisar transformar uma sequencia de perguntas em um fluxo logico. Este projeto pratica essa construcao usando um exemplo de compra simulada, com dados digitados pelo usuario, valor informado e validacao de uma senha ficticia.

## Como funciona

O script solicita informacoes pelo terminal, recebe o valor da compra e pede uma senha de confirmacao. Em seguida, compara a senha digitada com uma senha demonstrativa definida no proprio codigo e informa se a compra simulada foi confirmada.

## Conceitos utilizados

- Entrada de dados com `input`.
- Conversao de texto para numeros com `int` e `float`.
- Formatacao de mensagens com f-strings.
- Estrutura condicional com `if`.
- Repeticao com `for`.
- Organizacao sequencial de um fluxo interativo no terminal.
